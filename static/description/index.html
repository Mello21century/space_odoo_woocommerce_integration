WooCommerce Inventory & Sales Integration

Free-to-use stock API • Token security • Automatic stock push • Order import

What it does

  • Free-To-Use Stock API — one REST endpoint (GET /api/v1/stock) returning barcode, product_id and stock for every product with a barcode. The stock figure is Odoo's Free To Use quantity (on hand minus reservations), so external systems never oversell reserved goods.
  • Multiple API tokens — generate as many tokens as you need, each with its own expiration date. Tokens are stored hashed and shown only once.
  • Stock push to WooCommerce — POS orders, sales order confirmations and stock reservations automatically queue a stock update for the matching WooCommerce product (matched by Odoo barcode = Woo SKU). Updates are batched and never slow down checkout.
  • Order import from WooCommerce — a Woo webhook delivers new store orders to Odoo: customer (matched by email or created), products, quantities, sold prices, discount and delivery fees. The sales order is confirmed automatically so stock is reduced.
  • Safe by design — HMAC-verified webhooks, idempotent order import (no duplicates), failed orders held in a visible log with a readable reason and a Retry button.

Setup in 4 steps

  1. Connect the store — WooCommerce Integration → Store Connections: enter your store URL and the REST API consumer key/secret (WooCommerce → Settings → Advanced → REST API), pick a warehouse, then click Test Connection.
  2. Configure the webhook — in WooCommerce (→ Settings → Advanced → Webhooks) add an Order created webhook pointing to https://<your-odoo>/woo/webhook/order/<connection id> with the same secret you saved on the connection. Optionally add Order updated for cancellations/refunds.
  3. Match products — set each Odoo product's Barcode to the WooCommerce product SKU. Matching is automatic from there; make sure "Manage stock" is enabled on the Woo product.
  4. Create an API token (optional) — WooCommerce Integration → Generate API Token, copy the one-time value, and call the stock API from any external system.

Monitoring

Inbound Orders shows every order received from the store with its result; errors keep the raw payload and can be retried after you fix the cause (e.g. a missing barcode). Stock Push Queue shows pending/failed pushes with a requeue action.
